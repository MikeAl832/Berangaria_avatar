# Berangaria Avatar Runtime

Локальный Unity 2022.3-проект VRM-аватара для `D:\Projects\Berangaria_agent`.
Windows-сборка работает как прозрачный безрамочный click-through оверлей на
основном мониторе, а не как отдельное окно с фоном.
Для DWM-прозрачности release builder отключает несовместимый DXGI flip-model и
использует D3D11 BitBlt swap chain; не убирай соответствующий аргумент из BAT.

## Обычный запуск

Unity Editor не нужен. Запусти `start-avatar.bat` либо общий
`D:\Projects\Berangaria_agent\start-with-avatar.bat`.

Аватар появляется справа внизу поверх окон и не перехватывает мышь. Нажми
`Ctrl+Shift+F8`, чтобы включить режим размещения. В нём модель можно перетащить,
колёсиком изменить масштаб, а клавишей Enter или Escape снова вернуть пропуск
кликов. Окно разрешено опускать ниже нижней границы рабочего стола — например,
чтобы скрыть ноги и оставить только верхнюю часть модели. Небольшая часть окна
всегда остаётся видимой. Позиция и размер сохраняются локально через Unity
PlayerPrefs.

## Работа в Unity

1. Запусти `open-unity-editor.bat` либо открой `D:\Projects\Berangaria_avatar`
   через Unity Hub. Лаунчер использует проверенный редактор Unity `2022.3.62f3`.
2. Для новой модели выбери `Berangaria > Replace Avatar VRM...` и укажи VRM 1.0.
3. Unity скопирует модель как `Assets/Characters/current.vrm`, пересоберёт сцену и откроет её.
4. `Berangaria > Open and Play Avatar` запускает проверку в редакторе.
5. `Berangaria > Build Windows Avatar` обновляет автономный Windows-плеер.

Python отправляет на `127.0.0.1:17891` только состояние, разрешённое имя эмоции
и уровень громкости. Тексты, изображения, микрофонное аудио и PCM-байты в Unity
не передаются. Поддерживаются `calm`, `sarcastic`, `disdainful`, `bored`,
`indifferent`, `confident`, `sighing` и `chuckling`; остальные значения Unity
игнорирует. Эмоция одновременно управляет мимикой, осанкой и подачей Fish Audio.
Смена состояния и эмоции выполняется перекрёстным затуханием примерно за одну
секунду; быстрым остаётся только lip-sync, чтобы рот совпадал со звуком.
Во время речи корпус плавно переносит вес и закручивается, плечи реагируют на
громкость, а руки, предплечья и кисти делают редкие асимметричные акценты.
Частота и размах жестов зависят от эмоции: `bored` остаётся сдержанной, а
`confident` и `chuckling` двигаются заметнее.

В Play Mode клавиши `1`–`4` выбирают состояние, `E` перебирает эмоции, Space
возвращает автоматический цикл, а F1 показывает диагностическую панель.

## Репозиторий и релизы

`current.vrm` хранится через Git LFS, потому что сцена напрямую ссылается на его
Unity GUID. Черновые VRM-файлы исключены из Git. `Library`, `Logs`, `Builds` и
остальное локальное состояние Unity также не публикуются.

VRM Meta разрешает любому использовать модель как аватар, в том числе в коммерческих
проектах, изменять её и распространять дальше. Указание автора Mike остаётся обязательным.
Если в персонаже есть часть, скачанная у другого автора, лицензия этой части сохраняется.
